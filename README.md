Project Summary & Key Findings

Overview
In this project, we performed a comprehensive Exploratory Data Analysis (EDA) on the Iris dataset to analyze flower features and identify key patterns across different species (Setosa, Versicolor, and Virginica).

 Key Insights
1. *Data Integrity*: The dataset contains 150 samples with zero missing values, providing a clean foundation for analysis.
2. *Feature Distinction: *Petal length and petal width exhibit a strong positive correlation and serve as the most effective features for distinguishing between species.
3. *Species Characteristics*: 
   - Setosa flowers have distinctly smaller petals compared to the other species.
   - Virginica flowers display the largest average petal length and width.
4. *Outputs Generated*:
   - species_summary.csv: Contains complete descriptive summary statistics grouped by species.
   - filtered_iris.csv: Contains filtered records for flowers with sepal length greater than 6 cm.
